# موقعي الأول

## وصف المشروع
هذا المشروع هو أول موقع لي باستخدام HTML و CSS.
تم إنشاؤه كواجب لمادة إنشاء صفحة HTML.

## ملفات المشروع
- index.html : الصفحة الرئيسية للموقع
- style.css : ملف التنسيقات والألوان
- README.md : ملف يوضح فكرة الكود

## شرح الكود في index.html
- header : رأس الصفحة، فيه عنوان الترحيب
- nav : قائمة التنقل، فيها الرئيسية والخصائص ومن نحن
- main : القسم الرئيسي للصفحة
- section features : قسم الخصائص، فيه 3 مميزات
- section about : قسم من نحن
- footer : نهاية الصفحة، فيها حقوق النشر 2026

## كيفية تشغيل الموقع
افتح ملف index.html في المتصفح
